Local Document Search 0.2.2 per Windows 11 x64. Installer offline per utente, senza Python preinstallato.

Questa versione aggiunge una guida integrata in italiano e inglese, disponibile con F1 e dal pulsante Aiuto. Le pagine e i controlli si adattano al ridimensionamento della finestra, con minimo 480×360 pixel logici. F5 continua a sincronizzare l'indice. Sono state aggiornate le istruzioni e le etichette di accessibilità.

La ricerca, i viewer PDF/TXT/Markdown, l'editor TXT/Markdown, la CLI e il formato degli indici conservano il comportamento della 0.2.1. Gli indici desktop con schema precedente richiedono una ricostruzione esplicita. L'aggiornamento mantiene la cartella di installazione registrata; chiudere l'app prima di avviare l'installer.

La disinstallazione conserva i dati per impostazione predefinita; la cancellazione richiede una scelta esplicita. Il pacchetto non è firmato digitalmente. Verificare il checksum `.sha256` dopo il download. Il commit di build e lo SHA-256 sono riportati nel manifest allegato.
